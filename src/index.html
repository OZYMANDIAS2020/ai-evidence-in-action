Verify it yourself

Verification recomputes the SHA-256 commitment, checks each Ed25519 signature against the published demo public keys, then recomputes the comparison from the records that verified and checks it against the verdict recorded in the bundle. Editing the verdict alone is detected even though every signature still passes. It verifies demo-record integrity, key attribution, and comparison consistency only—not that a real-world refund occurred.

Current verification: NOT VERIFIED YET

VERIFIED describes whether the evidence passed the integrity, pairing, and comparison checks. It does not mean a real refund happened, and it is separate from the AGREEMENT or DISAGREEMENT shown above.

Download offline verifier

Test tamper detection edits a throwaway copy of the current evidence, changing one value in the recorded comparison and nothing inside the signed records, then runs that copy through the same verifier this page uses. Your own evidence is left untouched.

Offline use: node verify.mjs ai-evidence-in-action-bundle.json. The verifier uses the public demo keys embedded in the script and does not contact this site.
